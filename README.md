# Screen Relay

Живая трансляция одного окна (BlueStacks или любого другого) с Windows-ПК на сайт и в Telegram Mini App.

```
ПК: ScreenRelay.exe → твой VPS (Docker + Caddy) → браузер / кнопка «📺 Live» в боте
```

## 1. Сервер: одна команда на VPS

Нужны Docker, Caddy и домен (A-запись на VPS). Бот лучше создать отдельный через @BotFather.

```bash
git clone https://github.com/Satoros1/screen-relay && cd screen-relay
./deploy/setup.sh
```

Скрипт спросит домен, токен бота, кому можно смотреть и GitHub-токен (про него ниже). Дальше он сам:
- сгенерирует секреты и запишет `.env`;
- соберёт и запустит контейнер (свободный порт выберет сам);
- пропишет домен в Caddy: в системный (`/etc/caddy/Caddyfile`) или в Caddy в Docker. Если не найдёт, покажет, что вставить;
- проверит HTTPS;
- выведет **код подключения** `sr1:…` для программы и ключ для просмотра в браузере.

Повторный запуск безопасен: токены сохраняются, сервер пересобирается. Так же обновляется сервер: `git pull && ./deploy/setup.sh`.

Бот получает кнопку «📺 Live» (Mini App) и **пишет тебе в Telegram**, если трансляция упала больше чем на минуту
(ПК не на связи / окно не найдено), а потом пишет, когда она восстановится.

## 2. ПК: программа

1. Скачай `ScreenRelay.exe` в **Releases** (справа на странице репозитория). Python не нужен.
   Если Windows покажет «неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».
2. Вставь код `sr1:…` в поле «Адрес» (или кнопка «📋 Вставить код»). Адрес и токен заполнятся сами.
3. Выбери окно в списке (BlueStacks подхватится сам). Нужна только часть окна? Выдели её мышкой на превью.
4. **▶ Начать трансляцию.** Внизу видно: в эфире / fps / трафик / сколько зрителей.
5. Сверни программу или закрой крестиком: она уйдёт в трей у часов и продолжит работать.
   Правый клик по значку: открыть / старт-стоп / обновить / выход.
6. Галочки «Начинать трансляцию сразу» и «Запускать вместе с Windows» включают полностью автоматический режим:
   после перезагрузки ПК трансляция стартует сама, в трее.

Что программа делает сама:
- захватывает окно, даже если его перекрыли. Если эмулятор так отдаёт черный кадр, переключается на захват с экрана;
- разворачивает свёрнутое окно, находит окно заново после перезапуска эмулятора, переподключается при обрыве сети;
- если картинка не меняется, кадры почти не шлются.

На этом ПК выключи сон и блокировку экрана: на заблокированном экране Windows отдаёт черные кадры.

## 3. Обновления

Кнопка «Проверить обновления» в программе. Ещё программа сама проверяет при запуске и раз в 6 часов.
Обновление ставится в один клик: скачать, заменить себя, перезапуститься. Трансляция продолжится.

Репозиторий приватный, поэтому программа берёт обновления **через твой сервер**: при установке укажи GitHub-токен
(github.com/settings/personal-access-tokens → Fine-grained → доступ только к `screen-relay`, *Contents: Read-only*).
Другой вариант: сделать репозиторий публичным, тогда токен не нужен.

**Выпустить новую версию:** подними `APP_VERSION` в `desktop/ScreenRelay.pyw` (0.1.2 → 0.1.3) и запушь в `main`.
GitHub сам соберёт exe, проверит его на Windows (запуск, трей, автозапуск, самообновление) и выложит релиз.
