# Screen Relay — живая трансляция окна BlueStacks на сайт и в Telegram

```
BlueStacks на ПК → приложение Screen Relay → твой VPS → сайт / Telegram Mini App
```

## 1. Сервер (VPS) — один раз

```bash
cp .env.example .env        # заполни PUSH_TOKEN, VIEW_KEY, BOT_TOKEN, ALLOWED_IDS
python3 -c "import secrets;print(secrets.token_urlsafe(32))"    # сгенерить токены
docker compose up -d --build
```

Добавь блок из `Caddyfile.example` в свой Caddyfile → `caddy reload`.
Проверка: `https://live.твойдомен/health`.

**Telegram:** BotFather → бот → Bot Settings → Menu Button → `https://live.твойдомен/`.
Смотреть могут только ID из `ALLOWED_IDS`. В обычном браузере страница спросит `VIEW_KEY`.

## 2. ПК с эмулятором

**Скачай `ScreenRelay.exe`** в разделе **Releases** этого репозитория (справа на главной странице) и запусти.
Python не нужен. Windows может предупредить «неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».

### В приложении
1. Впиши адрес `wss://live.твойдомен/ingest` и токен (= `PUSH_TOKEN`).
2. Выбери окно в списке. BlueStacks подхватится сам, если он запущен.
3. Если нужно не всё окно, выдели мышкой область на превью. Правый клик сбрасывает.
4. **▶ Начать трансляцию.** Внизу видно: в эфире / fps / трафик / сколько зрителей.
5. Сверни программу или закрой крестиком: она уйдёт в **трей у часов** и продолжит транслировать.
   Значок зелёный, когда идёт эфир. Правый клик по значку: открыть / старт-стоп / выход.
6. Галочки «Начинать трансляцию сразу» и «Запускать вместе с Windows» делают так,
   что после перезагрузки ПК трансляция стартует сама, сразу в трей.

Повторный запуск exe не открывает вторую копию, а просто показывает уже запущенную.

### Как оно себя ведёт
- Окно захватывается **даже если его перекрыть** другими окнами. Если эмулятор отдаёт так черный кадр,
  приложение само переключится на захват с экрана (тогда окно не перекрывать) и раз в 30 с пробует снова.
- Свёрнутое окно приложение само разворачивает (без фокуса).
- Перезапустил эмулятор — окно найдётся заново само. Пропал интернет — переподключится само.
- Если картинка не меняется, кадры почти не шлются → трафик около нуля.
- Настройки сохраняются в `%APPDATA%\ScreenRelay\settings.json`.

## Новая версия exe

GitHub собирает exe сам при каждом пуше в `main` (Actions → последний запуск → Artifacts).
Релиз создаётся сам из `APP_VERSION` в `desktop/ScreenRelay.pyw`: подними версию (0.1.0 → 0.1.1), запушь в `main`, и в Releases появится новый exe.
Собрать локально: `desktop/build_exe.bat`.

### Что нужно на этом ПК
- Отключить сон и блокировку экрана (на заблокированном экране Windows отдаёт черные кадры).
- Окно эмулятора держать нормального размера: от него зависит качество картинки.
